# Расчет подсетей IPv4

Работа выполнена на ПК с установленным Cisco Packet Tracer.

###*Задачи*

Часть 1. Определение подсетей по IPv4-адресу
Часть 2. Расчет подсетей по IPv4-адресу

*Общие сведения/сценарий*

Умение работать с IPv4-подсетями и определять информацию о сетях и узлах на основе известного IP-адреса и маски подсети необходимо для понимания принципов работы IPv4-сетей. Цель первой части — закрепить знания о том, как рассчитывать IP-адрес сети на основе известного IP-адреса и маски подсети. Зная IP-адрес и маску подсети, вы всегда сможете получить другие данные об этой подсети.

#### Вопрос для повторения

- Почему маска подсети так важна при анализе IPv4-адреса?

Маска подсети определяется, какая часть IP-адреса узла сети относится к адресу сети, а какая — к адресу самого узла в этой сети (конкретному устройству). С помощью неё можно настраивать трафик в сети и коммуникацию между оборудованием, что удобно. Поэтому зная маску конкретной подсети можно сделать вывод о размере той или иной организационной сети, а также провести анализ ресурсов своей собственной.
